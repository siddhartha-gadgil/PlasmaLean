# Phase 5 (Cycle 5): one consistent plasma, certified Mercier stability, near-QA alphas for 0.19 s — 20 October 2026

## Outcome

Phase 5 of the [implementation plan](implementation-plan.md) adds **8 Lean modules** and a second kernel change (K2). It also rewrites the near-QA certificate in proof-term style. The library has no project axioms; the audit covers 7309 declarations.

- **One consistent plasma** (`Design.SolovevBand.solovev_one_plasma`). This is the first theorem that ties confinement and temperature to a single plasma. It covers one field B, the reactor Solov'ev equilibrium (5 T, axisymmetric), with pressure p_eq + Δ (Δ = 40 kPa):
  - B satisfies the kernel force balance on the transport domain s ≤ 1;
  - every 3.5 MeV alpha born at s ≤ 3/11 stays in s ≤ 1 for all time;
  - for every Bosch–Hale reactivity, χ₀ ∈ [8/5, 33/20] and edge temperature in [1, 3/2] keV, every supplied classical solution of the (quasilinear, density-weighted) transport law starting in the band stays in [T_sub, T_sup] for all t ≥ 0, with T ≥ 10 keV on s ≤ 3/10;
  - plasma pressure stays ≤ p_eq + Δ everywhere on s ≤ 1.

  **Scope:**
  - The transport geometry enters through a **supplied class** `IsSolovevGeometry`: bounds on V′-weighted averages taken from a numerical quadrature table, with only a model instance. Proving that the actual Solov'ev field satisfies it is in progress, using the new validated quadrature.
  - The certified parameter set is driven (≈ 120 MW auxiliary heating, Q ≈ 5.5). The note's ignited set fails, because the 1 keV Bosch–Hale windows leave ≈ 10% slack near ignition.
  - χ is a rational T² stand-in; Δ represents an edge pedestal whose current sheet is outside the kernel.
- **Kernel change K2** (recorded in `Kernel/Transport.lean`): the diffusivity may depend on temperature, D(ψ, T). Comparison theorems extend (the touching argument is unaffected), and upper barriers are proved directly.
  - **First two-sided band:** `Design.QuasilinearBarrier.quasilinear_band`, in the cylinder with χ = χ₀(1/10 + T²/100). T stays in [T_sub, T_sup], ≥ 10 keV in the core and ≤ 23.5 keV, using Kirchhoff-transform barriers.
  - **Fixed-χ obstruction lifted, numerically only:** steady-state Q ≈ 9.5–17, above the fixed-χ limit of ≈ 6.
- **Mercier stability certified for the reactor Solov'ev equilibrium** (`Design.SolovevMercierCertified.reactor_mercier_stable`). The exact axisymmetric Mercier index is positive on every flux surface 0 < ψ̃ ≤ L⁴/16, by validated quadrature (18 × 32 cells, margins 3–6%) in a new fixed-point interval library. A genuine magnetic well (V″ < 0) is proved. This is still modulo the supplied general Mercier formula and a stated change of variables; it is local interchange stability, a necessary condition.
- **Near-QA passing alphas: 0.19 s** (up from 0.11 s), and the certificate build fell from ≈ 349 s to 59 s.
  - The amplitude polynomial is computed once (a literal checked by one kernel evaluation).
  - A two-stage enclosure, plus an adaptive cover proved as an explicit proof term (`CoverCert`, SubsetSum pattern, 324 leaves).
  - 0.19 s is about half the slowing-down time. A fourth averaging step is infeasible in the kernel for now.
- **Trapped alphas in near-QA:**
  - single magnetic well per poloidal turn, proved at fixed φ and along every field line (the ripple shifts the minimum, refuting a draft lemma);
  - per-bounce identities;
  - a bounded non-resonant drift over N bounces.
  - The kick form and non-resonance remain hypotheses.

## Corrections and challenged claims

- **K2 review:** no soundness bug. Minor items were fixed: chain-rule caveat in the kernel doc, corner-compatibility explanation, stand-in disclosure, density-weight docstring.
- **A sub-agent report was inaccurate.** The agent that built `SolovevOnePlasma.lean` reported rigorous V′ and flux-average bounds for the actual Solov'ev field (`solovevVp_bounds` and others) that do not exist in the code. The integrating agent found the gap and replaced the claim with an explicitly supplied class plus a model instance. From now on every reported declaration is grep-checked before it is cited; all names in this report were checked.
- **Parameter honesty:** the ignited "one plasma" set from the design note could not be certified; the driven set (Q ≈ 5.5) was, and that is what is claimed.
- **Wording:** stale future-tense phrases in the slides and landing page ("planned kernel", "will formalize") were updated against the code. Remaining planned items are still marked as planned.
- **Skill:** `decide_cbv` was tested and the proof-engineering skill updated. It works where `decide +kernel` gets stuck (well-founded recursion), but it is 5–20× slower on the existing ℚ checkers, so `decide +kernel` remains the fallback for those.
