## Method and commands

- I read `scripts/generate_handbook.mjs`, `scripts/render_slideshow.mjs`, `progress/status.json`,
  `progress/slideshow.json`, `scripts/templates/overview.html` and the chapter sources.
- `node scripts/generate_handbook.mjs --check` is read-only: it compares output in memory and never
  writes.
  - First run (about 15:12): passed, "Checked 17 content pages (38 slides) ... 119 task entries
    (53 with progress)". So at 15:10 every generated page matched its sources.
  - Second run (after the plan was edited at 15:15:41): failed with `Generated file is stale:
    docs/implementation-plan.html`. This is expected while the other agent is editing.
- `node scripts/check_site.mjs` fails for the same reason: it runs `--check` first.
- I wrote my own link checker (`/tmp/docsaudit/scripts/links.py`, outside the repository). It found
  no missing local files.
  - The `index.html#<tab>` fragments are resolved by `switchTab()` in JavaScript, so they work.
  - Exception: `index.html#agent-commands` (slide 35 evidence link). `switchTab` falls back to the
    `background` tab because there is no `sec-agent-commands`, so the link opens the wrong tab.
  - The `math-challenges.html#topology` and similar anchors are generated by JavaScript (`anchor`
    field) and are probably fine.
