# Untrusted oracle scripts for the Solov'ev high-Q / ignited bands

Scratch scripts used to search for barrier coefficients and to generate the fine Bosch–Hale
windows (`bhfine.py`, `gen_bh.py`) and the Lean data for
`PlasmaLean/Design/SolovevBandHighQ.lean` and `SolovevBandIgnited.lean` (`cfg_hq.json`,
`cfg_ign.json`). They only propose candidates; every claim is checked in Lean. Not maintained
as a tool. Copied from the working directory used on 20 October 2026; they may refer to
intermediate files that were not kept.
