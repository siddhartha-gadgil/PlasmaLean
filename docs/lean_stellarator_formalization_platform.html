Immediately following every `def` or `structure`, the agent MUST formulate and prove characterizing `@[simp]` lemmas so that downstream code avoids unfolding raw definitions.

Rule 2: Preferred Proof Tactics

Agents should prioritize robust tactics: `aesop` for structural goals, `calc` blocks for tensor manipulation, `positivity` for norm bounds, and `gcongr` for inequalities.

Rule 3: Docstrings & Math Notes

Every file must feature module documentation `/-! ... -/`. All definitions and theorems must include explicit Lean docstrings `/-- ... -/` with LaTeX formulas.
