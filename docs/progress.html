Outcome

This run adds 2 Lean modules; the audit covers 21322 declarations, all standard axioms.

  • Design.RationalStellarator.rationalStellarator_confined_forever_exists (no hypotheses). There is a torus profile ρ with 0.077 ≤ ρ ≤ 0.19 around the magnetic axis of the exact stellarator field B = ∇φ + ¼∇h such that:
  • from every point on the axis or inside the torus there is exactly one two-sided field line, defined for all time;
  • every field line starting inside stays inside for all time.

This removes the last caveat of Phase 10, which quantified over field lines whose existence was not proved.

  • Generic ODE result (Fields.ODEGlobal.existsUnique_global): for a C¹ vector field on an open set in a proper normed space, a locally invariant subset of a compact set admits a unique global solution from each point. It is proved from uniform local existence (Picard–Lindelöf), extension and Grönwall uniqueness. Interval versions of the barrier and torus-trapping theorems (invariantBarrier_Icc, torus_trapping_Icc) supply local invariance.
  • Corollaries: rationalStellarator_confined_fieldLine_through (a confined field line through every point of the region) and axis_unique_fieldLine.

Scope: magnetic field lines of the exact vacuum model field; not particles, not finite β, not coil-produced.
