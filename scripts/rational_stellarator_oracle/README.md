# Untrusted oracle scripts for the rational-stellarator confinement certificate

Scratch scripts (fitting the approximate first integral, planning covers, emitting Lean data) used
for `PlasmaLean/Design/RationalStellaratorConfined*.lean` and `RationalStellaratorCover.lean`.
They only propose candidates; all claims are checked by Lean. Copied from the working directory
of 20 October 2026; not maintained, and may reference intermediate files that were not kept.
