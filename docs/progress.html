Implementation status · 2026-10-14Exact finite-pressure equilibria (toroidal Solov'ev and a nonaxisymmetric helical one) now satisfy the kernel force-balance law, with all-time full-orbit confinement theorems, filament Maxwell identities, and Suydam/Newcomb stability criteria with exact certificates. All are idealized symmetric models; no coil-produced stellarator is certified and no all-mode MHD stability is proved. Compiled declarations, build results and assumptions → Chapter notes retain their original planning context; the task progress fields report subsequent work.

Outcome

This run moves the library from a vacuum calibration fixture to exact finite-pressure MHD equilibria with all-time confinement theorems, plus the first stability criteria with both sufficiency and necessity. Twenty-one new Lean modules add 443 source theorems (including helpers). Highlights:

  • Maxwell identities. The closed-filament Biot–Savart field satisfies ∇·B = 0 and ∇×B = 0 away from the coil, for the actual Fréchet derivative of the continuous integral. The run-2 boundary obligation is closed.
  • Local interchange stability. A sharp Hardy inequality yields the Suydam criterion for the model radial form, both ways: sufficiency with a coercive margin, and an explicit unstable mode in every neighbourhood of the resonance when it fails. Newcomb/Picone/Riccati certificates generalize this to variable coefficients. An exact rational polynomial interval checker, run by the kernel without native_decide, discharges such certificates.
  • Equilibria satisfying the domain-kernel law ForceBalance (J × B = ∇p with the actual Ampère current):
  • an exact toroidal Solov'ev equilibrium (axisymmetric; ITER-like scale R₀ = 6 m, B = 5 T, β_axis = 147/5000);
  • an exact helically symmetric, nonaxisymmetric equilibrium (straight-stellarator model; 5 T, β_axis = 4%, pitch length 2 m).
  • Confinement for all time. Noether conservation of canonical momentum for any Killing symmetry, together with an intermediate-value trapping lemma, proves that every full Newton–Lorentz orbit below a stated rigidity stays in a stated flux region forever, in both equilibria. Field lines are confined by exact first integrals.
  • Imperfect symmetry. A symmetry defect δ gives confinement for an explicit time ∝ 1/(δ|v|) (a ripple example). The run also records that this crude bound is far from reactor-relevant.
  • Screw-pinch design. A realistic cylindrical screw pinch (a = 1 m, R₀ = 4 m, B ≈ 5 T, ⟨β⟩ = 2/75) satisfies Suydam's criterion everywhere with a 25% relative margin and q ≥ 5/4.

This is not a practical stellarator design. No configuration here is produced by coils, and the symmetric models exclude toroidal curvature (helical case) or nonaxisymmetry (Solov'ev case). For the cylindrical screw pinch, Newcomb-reduced ideal δW ≥ 0 is certified for all modes with 1 ≤ |m| ≤ 6 (wall at the edge), but not yet uniformly in m. No all-mode or global MHD stability certificate exists for the Solov'ev or helical equilibria. Gate status: P2 remains partial. P3 (confined reduced orbits) and P4 (finite-pressure equilibrium) now have checked instances in idealized symmetric models, not for a coil-produced stellarator. P5 has local (Suydam) and certificate-based (Newcomb) building blocks only.

Baseline checkout: b8641a11c5d9e8bfde98b3ef2711a327084890f2. Lean and Mathlib remain v4.34.1; there is no dependency change. The domain kernel (Kernel/*.lean) was re-audited and needed no correction or addition; every new equilibrium is checked against the existing ForceBalance class. No solver or floating-point output enters any proof. Python/sympy were used only to search for candidates (equilibrium ansätze, profile parameters, Jacobi polynomial certificates).

Implementation loops

  1. Re-audited the kernel, last report and roadmap. The selected targets were the Maxwell gap, local stability, field-line barriers and full-orbit dynamics, developed in parallel.
  2. Maxwell identities for filament fields (divergence and curl operators with sanity lemmas; FTC along the closed curve).
  3. Hardy inequality → Suydam sufficiency, sharpness and necessity (logarithmic test mode).
  4. First integrals and field-line barriers; a nonaxisymmetric analytic Clebsch torus. It was then shown to be divergence-free but not a vacuum field: its curl is nonzero throughout the region. One planned claim was corrected; see below.
  5. Newton–Lorentz energy conservation, exact gyration and realistic Larmor radii.
  6. Newcomb/Picone/Riccati certificates; an exact polynomial interval checker with soundness, wired to the certificates.
  7. Screw-pinch force balance, safety factor and Suydam criterion, with a realistic Suydam-stable exact profile.
  8. Canonical toroidal momentum: an all-time band, IVT trapping, a symmetry defect and a first-exit bootstrap for finite-time confinement.
  9. Observation: the polynomial flux function satisfies Δ*ψ = 3R², i.e. it is a Solov'ev Grad–Shafranov solution. This led to an exact toroidal equilibrium verified against the kernel, with an SI instance.
  10. Noether conservation for Killing fields; a helically symmetric rotating-ellipse field; then an exact helical ideal-MHD equilibrium found by symbolic search, ∇·B = 0, kernel force balance, and an SI reactor-scale instance.
  11. Newcomb (m,k) mode analysis of the screw-pinch example: coefficients extracted from Newcomb 1960 / Glasser et al. 2020 (Eq. 2) and cross-checked against Freidberg's form and the Suydam limit (weight Bθ²/B² recovered exactly). Every mode with 1 ≤ |m| ≤ 6 and every integer n is certified, by kernel-checked Picone certificates (9 resonant/kink-candidate modes) and potential checks (18 modes), plus uniform families.

Obstruction recorded. 3.5 MeV fusion alphas are not covered in either equilibrium. In the Solov'ev case their normalized rigidity is about 1/31, against the 1/64 required. The crude canonical-momentum band confines them only to ψ̃ ≲ 0.16, beyond the pressure boundary ψ̃ = 1/16. Under symmetry breaking, the full-orbit defect bound gives times ∝ 1/(δ|v|), a ballistic time scale far shorter than slowing-down times. Practical alpha confinement in a quasisymmetric stellarator needs guiding-centre averaging and orbit-width theory (roadmap R4, R6).

Corrections and challenged claims

  • The Clebsch-torus field was first planned to have positive vertical curl throughout its region. That is false: the vertical curl changes sign at R² = 4/3, inside the region. Non-vacuum status is proved with the horizontal components instead.
  • The screw-pinch exploration showed that p ∝ (1 − r²) or (1 − r²)² always violates Suydam near the axis, because p′ ∼ r while the shear term ∼ r³. The certified profile uses p ∝ (1 − r⁴).
  • The helical equilibrium formula continues to negative pressure outside ψ_b. Setting p = 0 there with the same field is not an equilibrium, since (∇×B)×B ≠ 0, so a current sheet and a different exterior field would be needed. Claims are restricted to ψ ≤ ψ_b, which the covered orbits never leave. The orbit hypothesis is still stated for the smooth field on all of space.
  • A helically symmetric rotating-ellipse family with F = −2ψ is also an equilibrium, but its field vanishes on the axis. The run used the second family (F = 4 + 2ψ, μ₀p′ = −4).

Next boundary

  1. Stability of the new equilibria. Prove Mercier-/Suydam-type local criteria and Newcomb-type global certificates for the helical and Solov'ev equilibria. Formalize the δW reduction rather than citing it.
  2. Break the symmetry correctly. Move from exact helical symmetry to toroidal quasisymmetry. Bound the defect for a near-axis quasisymmetric configuration, and develop guiding-centre averaging so that the confinement time scales with the slowing-down time instead of the ballistic time.
  3. Coils. Couple an equilibrium boundary to a coil set (free-boundary/vacuum matching) using the now-proved Maxwell identities, and resume the four-coil VD1 dataset.
  4. Energetic alphas. Find configurations, or sharper orbit-width bounds, that cover 3.5 MeV alphas inside the plasma.
