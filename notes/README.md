Method notes for a LeanTheory project. Domain content goes into the plan; the other notes are
generic and should be adapted, not replaced.

- [`implementation-plan.md`](implementation-plan.md): skeleton of the plan of record (goals,
  corrections, layers, cycle, theory tracks, model ladder, schedule, sub-agent template,
  definition of done, progress log, evidence gates, implementation log). Fill in the ‹…› slots.
- [`domain-libraries.md`](domain-libraries.md): how to build a kernel / sanity / library domain
  model in Lean (laws as typeclasses, no axioms, the sanity triad) and how agent runs proceed.
- [`formalization/`](formalization/README.md): model contracts, the meaning of a design proof.
- [`goals/`](goals/README.md): generic guidance on choosing and stating goals.
