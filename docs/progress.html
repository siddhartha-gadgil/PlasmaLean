Implementation status · 2026-10-21Passing 3.5 MeV alpha guiding centres confined for all time in an exact stellarator field over a positive-measure set of pitch angles (μ ∈ [0, E/(16B₀)], one energy and B₀R₀; Littlejohn model), and for μ = 0 over B₀R₀ ∈ [67.95, 69.99] T·m; a Mercier-stable finite-β non-axisymmetric band with labels derived from the field; all-time field-line confinement; 52-transit coil confinement; one consistent axisymmetric plasma with certified local stability up to ignition. Compiled declarations, build results and assumptions → Chapter notes retain their original planning context; the task progress fields report subsequent work.

Outcome

This run adds about 120 Lean modules (most are certificate modules). The library has no project axioms; the audit covers about 56k declarations.

  • First all-time confinement over a positive-measure set of pitch angles (Design.RationalStellaratorGC.alpha_gc_passing_confined_forever, gc_mu_passing_confined_forever_SI, rationalStellarator_gc_mu_confined_forever). Setting: 3.5 MeV alphas (CODATA-rounded mass and charge), B₀R₀ = 256 m v/(2e) ∈ [68.9, 69] T·m.
  • Statement: for every magnetic moment μ ∈ [0, E/(16B₀)] — initial pitch angles with sin²χ ≤ |B|/(16B₀), about 14.5° near the axis (informal) — there is a torus profile P (0.03 ≤ P ≤ 0.255 in units of R₀) such that every guiding-centre orbit with v_∥(0) > 0 that starts inside stays inside for all time and stays passing; such orbits exist from every interior point.
  • Method:
  • passing orbits are reparametrized field lines of B + ∇×(ρ_{E,μ} b), with the grad-B drift absorbed exactly (GCPassing);
  • a Chebyshev-in-λ family of exact KAM tori with uniform constants (smallness 0.098);
  • a bootstrap (curve_eq_of_local) proves passing rather than assuming it.
  • Cost: ≈ 28 CPU-minutes, ≤ 5.5 GB per process. It is in the default build.
  • Independent review: sound. It confirmed the field identity, uniform λ coverage, the non-circular bootstrap and genuine existence.
  • Scope (corrected after review): positive measure in pitch angle only, at a single energy and a single B₀R₀; still measure zero in 3-D velocity space. Littlejohn model supplied, non-relativistic, collisionless (no slowing-down), static vacuum model field, not coil-produced. The range [0, 1/16] rather than [0, 1/8] is set by kernel memory (6.3–6.6 GB for degree 15).
  • Mercier-stable finite-β band, now with derived labels (Design.LandremanFamily2Cert.family2_mercier_stable_derived). The coordinate map, its Jacobian (= JacR), Lebesgue volume, toroidal and poloidal flux, enclosed current and the coarea formula are proved from the field (LandremanFamily2Coords/FluxLabels/Coarea), and ι′ > 0 and V″ > 0 are certified on k ∈ [0.7, 0.9] (family2_shear_hill). The band's main caveat is removed; the Landreman–Jorge Mercier formula remains supplied.
