Compiled declarations, build results and assumptions → Chapter notes retain their original planning context; the task progress fields report subsequent work.

Outcome

Phase 2 of the implementation plan adds 14 Lean modules. The library has no project axioms; the audit covers 3491 declarations.

  • First all-time core-temperature bound in a transport model (M2). Design.TransportBarrier.m2_core_barrier covers every supplied reactivity satisfying the Bosch–Hale class and every χ ∈ [0, 0.5] m²/s (χ here includes the 3/2 heat-capacity factor; in the conventional q = −nχ∇T normalization this is χ ≤ 0.75 m²/s). For every classical solution of the flux-surface heat equation that starts above a degree-10 barrier profile, with edge temperature ≥ 1 keV, the temperature stays above the barrier for all t ≥ 0. The barrier is ≥ 10 keV on ψ ≤ 0.3 and 16.4 keV on the axis.
  • Setting: an idealized straight cylinder (a = 2.5 m, R₀ = 6.5 m, n = 10²⁰ m⁻³, carbon impurities with Z_eff = 1.7) with ≈ 70 MW of deposited auxiliary heating.
  • Proof: a 16-piece exact margin certificate (N[T_sub] ≥ 1/20 keV/s), plus a new comparison theorem for an axis where the diffusivity degenerates.
  • Burn window from an empirical scaling law (M1). The ad-hoc τ_E hypotheses are replaced by IPB98(y,2) for an ITER-like tokamak. With P_aux ∈ [50, 70] MW and H ∈ [1.25, 2], T(t) ∈ [10, 30] keV for all t ≥ 0. The obstruction at nominal H ≤ 1 is also proved. The ignition point lies in (12, 13) keV and is unstable. The Bosch–Hale class is shown to be non-vacuous by an explicit interpolant whose 61 windows are checked by a proof term built step by step.
  • All-mode stability of the screw-pinch example. Design.ScrewPinchModesHighM.stable_all_modes proves Newcomb stability for every integer (m, n) with m ≠ 0 (the reduction itself remains a supplied interface). Ingredients: a scaling argument (stability is monotone in m²) and an analytic Picone function closing the previously open band.
  • Ballooning and Mercier (T2).
  • Barta certificate with weight for the 1-D ballooning operator.
  • An exact iff for constant coefficients (energy ≥ 0 exactly when L ≤ (π/2)√(p/(−q))).
  • Cylindrical Mercier ⇔ Suydam, with guards for shearless surfaces.
  • Minimum-B obstruction (T1/T8). In vacuum, ∇⊥|B| = |B|κ. Hence at a critical point of |B| field lines have zero curvature, and no closed field line can carry a transverse minimum of |B| everywhere. This result is non-vacuous: a straight-wire field with a circular field line is a witness, and the theorem is meaningful only in multiply connected regions.
  • Filament fields are C^∞ off the coil, so closed coils are vacuum-field instances without extra hypotheses.
  • Discrete maximum principle (T5). The backward-Euler finite-volume scheme for radial transport is an M-matrix for every time step, giving discrete comparison over all steps. The second-order SBP identity is proved for every N.

All of this is still idealized: a straight cylinder rather than a stellarator geometry, prescribed constant χ, fixed density, and supplied solutions. Screw-pinch stability relies on the supplied Newcomb reduction.

Corrections and challenged claims

  • Review findings, all fixed:
  • The Mercier predicate held spuriously on shearless surfaces (division by zero); it now has guards.
  • The curvature obstruction gained a non-vacuity witness and a remark on multiply connected regions.
  • The scaling classes require positive power, to avoid Lean's 0^(−α) = 0.
  • Numerical-only observations (ISS04 rejected, H ≳ 1.22) are labelled as such.
  • M2 review (lane E) found no soundness issue; it recomputed the coefficients, units, reactivity floor, axis argument and power figures. The satisfiability lemma checks only the inequality hypotheses: a solution cannot start exactly at T_sub with a constant edge, because the corner compatibility condition N[T₀](1) = T_edge′(0) fails. AxisFreeSolution.corner_compatibility and tsub_not_initial_data prove this. m2_compatible_initial_profile constructs a compatible initial profile T₀ ≥ T_sub, so the initial, edge and corner conditions can be met together. Wording on axis characteristics and the χ normalization was corrected.
  • Kernel limitation found. TransportLaws demands D ≥ D_min > 0, which no coordinate with ψ ∝ r² can satisfy at the axis. M2 therefore uses a separate degenerate-axis class. Relaxing the kernel is scheduled for Phase 3.
  • Layering. The theory modules no longer import sanity modules (modeField moved; filamentField_vacuumField' moved to Sanity/FilamentVacuum).
