Self-Contained Lean 4 Invitations for Geometers & Topologists

Want to contribute to PlasmaLean without learning plasma physics first? Each of the six invitations below is a short, self-contained Lean 4 stub file (under 40 lines, Mathlib imports only) with a sorry to replace. The stubs are not part of the library build; a solution would be adapted into the library (its conventions, namespaces and the no-decide rule) before use. Each card says what the library already contains on the topic (checked on 30 October 2026): Challenge 6 is partly done in the constant-metric case, and Challenge 1 overlaps the kernel and the explicit torus map of the Grad counterexample.
