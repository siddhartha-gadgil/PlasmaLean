Outcome

This run adds 7 Lean modules completing the guiding-centre route. The library has no project axioms.

  • Design.RationalStellaratorGC.alpha_gc_confined_forever. There is a torus profile ρ with 0.03 ≤ ρ ≤ 0.253 (in units of R₀) around the magnetic axis of the exact stellarator field, scaled to SI as B₀·field(1/4)(x/R₀). For alpha mass and charge in CODATA-rounded intervals, and B₀R₀ fixed by the gyroradius condition m v/(2e B₀R₀) = 1/256 (B₀R₀ ∈ [68.9, 69.0] T·m, proved), we have:
  • Existence: from every point inside the scaled torus there is a guiding-centre orbit with μ = 0 and parallel speed v = √(2·3.5 MeV/m);
  • All-time confinement: every such orbit (μ = 0, v_∥(0) = +v) starting inside stays inside for all time.
  • Supporting results:
  • rationalStellarator_gc_field_confined_forever: all-time field-line confinement, with unique global existence, for the guiding-centre field B + (1/256)∇×b.
  • rationalStellarator_gc_confined_forever: the same for μ = 0 Littlejohn orbits.
  • gcField_cylPt_real / gcField_cylPt link the field to the certified flow form.
  • gcField_contDiffOn gives C².
  • norm_field_ge gives |B| ≥ 1/10 on the tube.
  • BstarPar_field gives B*_∥ = |B| exactly (the field is curl-free).
  • Star-shapedness and winding certificates.
  • A generic FlowTorus layer for any C¹ field.
  • The orbit is shown directly to be a field line of (v_∥/|B|)·B̃, which avoids a circular use of the transfer lemma.
  • Independent review: sound. It checked the Littlejohn model against Cary–Brizard, the SI normalization (coefficient exactly +1/256), the orbit-to-field-line step and junk-value pitfalls; standard axioms only.

Scope (important). This covers a measure-zero set of alphas: exactly zero perpendicular energy (μ = 0), the full 3.5 MeV parallel energy moving forward (v_∥ > 0), and a single exact value of B₀R₀. Slowing-down, pitch-angle-scattered, trapped and v_∥ < 0 alphas are not covered, and nothing is robust in energy or B₀R₀. The guiding-centre (Littlejohn) equations are a supplied model; their validity at ρ_s/R₀ = 1/256 is assumed. The treatment is non-relativistic (v ≈ 0.043c). Collisions, electric fields and time dependence are excluded. The field is the analytic vacuum model, not coil-produced. This is not alpha confinement in general.
