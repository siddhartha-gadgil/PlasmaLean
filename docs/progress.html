Implementation status · 2026-10-21Passing 3.5 MeV alpha guiding centres (μ = 0; Littlejohn model) confined for all time in an exact stellarator field for every B₀R₀ in [67.95, 69.99] T·m (robust in B₀R₀; still measure zero in velocity space), for both signs of v∥; μ > 0 passing identity; trapped-alpha bounce certificates. Also: all-time field-line confinement; a coil-produced field confining field lines for 52 transits; one consistent axisymmetric plasma with certified local stability up to ignition. Compiled declarations, build results and assumptions → Chapter notes retain their original planning context; the task progress fields report subsequent work.

Outcome

This run adds about 90 Lean modules, most of them certificate modules. The library has no project axioms; the audit covers about 45k declarations.

  • Robust in B₀R₀ (Design.RationalStellaratorGC.alpha_gc_confined_forever_robust). For 3.5 MeV alphas (CODATA-rounded mass and charge intervals) in the exact stellarator field scaled to SI, and for every B₀R₀ ∈ [67.95, 69.99] T·m — a positive-measure range, ≈ −1.5%/+1.4% around the design value — there is a torus profile P (0.03 ≤ P ≤ 0.255 in units of R₀, depending on B₀R₀) such that passing guiding centres (μ = 0, v_∥ > 0) starting inside stay inside for all time; such orbits exist from every interior point.
  • Method: a Chebyshev-in-ρ family of approximate tori, certified by Kronecker-ball arithmetic with ρ = ρ_c + h cos ϑ as an extra variable (Certificates.KronBallCheb*).
  • Uniform constants: residual 2.7×10⁻²¹; C₂ ≤ 8.83×10¹⁰; smallness ≈ 0.073 ≤ 1.
  • gc_family_torus gives an exact torus for every ρ ∈ [63/16384, 65/16384].
  • Cost: ≈ 15 CPU-minutes, ≤ 5.2 GB per process. A fully parallel build can thrash memory on a 6-performance-core machine.
  • Independent review: sound. It confirmed coverage of every ρ, uniform constants, the SI map and the profile margins.
  • Both signs of v_∥ (Design.RationalStellaratorGCNeg.alpha_gc_confined_forever_pm): a second exact torus, with ι_B = (161 − √5)/1178, for ρ = −1/256 (residual 3.5×10⁻²⁴, node validity 0.38, smallness 1.3×10⁻³). Each sign has its own trapping region.
  • μ > 0 passing guiding centres (Kinetic.GCPassing): orbits are reparametrized field lines of the divergence-free field B + ∇×(ρ_{E,μ}b), with the grad-B drift absorbed exactly (passing_velocity_identity), using a new curl product rule (Fields.curl_fderiv_smul). The KAM torus for this field is not yet done.
  • Trapped alphas (Phase 12):
  • exact-QA all-time confinement (restated);
  • near-QA confinement proved for 1.8×10⁻⁴ s;
  • a tight validated bounce period (≤ 83 μs);
  • constructed reference orbits;
  • a re-anchored N-bounce framework.

Negative: the current amplitude bound (0.236) cannot close the re-anchored argument (it needs ≤ 0.13). Enclosing the oscillatory kick integrals (simulated ≈ 0.023) is in progress.

Scope. Still μ = 0 (a single pitch angle, measure zero in velocity space) for the confinement theorems. The Littlejohn guiding-centre model is supplied, the field is the vacuum model, and the treatment is non-relativistic with no collisions. The new robustness is in B₀R₀ only.
